# Курсовой проект: Магазин канцтоваров

## Описание
Программа для учёта товаров, продаж и закупок в магазине канцтоваров.
Есть консольная версия (kursovaya.py) и графическая (shop_gui.py).

## Текущая версия
Программа подключена к удалённой тестовой БД №4 (db_vgu_test4).
Все таблицы созданы с уникальным префиксом `69420` для избежания конфликтов:
- 69420products
- 69420categories
- 69420sales
- и т.д.

Тестовые данные загружены.

## Как запустить
1. Установить зависимость:
pip install mysql-connector-python
2. Запустить графическую версию:
python shop_gui.py
Доступ к удалённой БД — по данным из файла #0.docx (или у преподавателя).
